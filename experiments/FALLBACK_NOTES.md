# Silent fallback demonstration

`fallback_demo.gif` is a 36-second loop assembled from six actual app-screen captures. It is a fallback walkthrough, with no fabricated chart values or voice narration.

1. Reference comparison on the loaded real route.
2. Combined simulated defects and the resulting before/current comparison.
3. Plain-language explanation of the time and on-time tradeoff.
4. Previously measured study results.
5. A saved individual trial and its evidence.
6. The review form and required acknowledgment.

The UI example route belongs to training, as the app states. It demonstrates the workflow, not held-out performance. The separate study uses four later-date test routes. No human approval or human review duration was fabricated during the recording. Automated UI checks leave only Pending comparisons; reviewers must supply their own names, notes and decisions.

The slides/deck were intentionally omitted at the user's request. Use the app, experiment report and this silent fallback for the demonstration.
